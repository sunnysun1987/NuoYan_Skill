# V2.3.0 Release Validation

Date: 2026-09-11

## Scope

This release addresses two user-facing failures:

- Windows Skill installation did not guarantee the Python runtime, Playwright Chromium, Argos dependency and English-to-Chinese model were installed together.
- Metric facts only derived Chinese labels in the HTML layer and did not provide a shared bilingual contract across knowledge data, HTML, Excel and Markdown evidence cards.

## Implemented

- Added standard and optional Windows asset manifests with path, size, SHA-256, license, required/optional and ordered source fields.
- Added local asset, enterprise mirror and public source fallback, plus `.nuoyan/install-state.json` provenance.
- Added a Windows asset builder for the Python 3.13.15 runtime, wheelhouse, Playwright Chromium and Argos en-to-zh model.
- Removed the `argospm` PATH dependency by installing local or indexed Argos models through the Python API.
- Added bilingual metric fact fields and translation cache entries, including mixed-language excerpt handling.
- Updated HTML, Excel and Markdown output. The HTML keeps the English original, shows a compact translation status and contains its wide table inside a local horizontal scroll region.

## Boundaries

- The repository stores manifest templates and build/install logic, not the large binary assets.
- The release ZIP has not been built because the current host is macOS and has no PowerShell runtime.
- Clean Windows 10/11 offline installation, mirror fallback and public fallback remain required release acceptance checks.
- The Argos model source and license must be reviewed in the generated `THIRD_PARTY_LICENSES.txt` before distributing the binary bundle.
- Java and Node are optional extension assets and are not part of the current standard readiness gate.
- No Git push, Git tag or GitHub release was performed.
