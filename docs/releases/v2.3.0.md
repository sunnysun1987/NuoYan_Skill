# 诺研 Skill v2.3.0

本版本为 Windows 用户提供可自行下载的完整离线安装包，并在指标事实环节增加中英双语速读。

## Windows 用户

下载 `nuoyan-windows-offline-installer-2.3.0.zip`，完整解压后双击 `INSTALL_NUOYAN.cmd`。安装包包含 Python 3.13 专用运行时、Python 依赖、Playwright Chromium 和 Argos English→Chinese 离线翻译模型，不要求预装 Git、Python、Node 或 Java。

安装完成后，在 Codex 插件管理中确认 Life Science Research、Browser、Chrome 已启用并重启 Codex。命令窗口退出码为 0 且体检结果显示 `standard_ready=true`，才表示标准调研环境可用。

## 主要更新

- Windows 安装支持本地离线资产、企业内网镜像、官方公网源三级回退。
- 所有运行时资产通过 release manifest 的文件大小和 SHA-256 校验。
- Argos 英中模型随标准离线安装包交付，避免调研报告出现“翻译引擎未就绪”。
- 指标事实增加中文指标名、英文标签、中文解释、中文摘录和翻译状态，并贯通 HTML、Excel 与 Markdown 证据卡。
- Java 和 Node 不是当前诺研运行时依赖，因此不进入标准包；后续需要相关控件时通过可选扩展资产提供。

## 校验与验收

`SHA256SUMS.txt` 用于核对下载文件完整性。`WINDOWS_VALIDATION_PROMPT.md` 可直接交给 Windows 环境中的 Codex 执行安装验收。

干净 Windows 10/11 电脑的离线安装仍属于发布后的人工验收项；严格体检未通过时，不应开始正式调研。
