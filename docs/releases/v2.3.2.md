# 诺研 Skill v2.3.2

本版本通过 GitHub Releases 提供 Windows 完整离线安装包，并在指标事实环节提供中英双语速读。

## Windows 用户

下载 `nuoyan-windows-offline-installer-2.3.2.zip`，完整解压后双击 `INSTALL_NUOYAN.cmd`。安装包包含 Python 3.13 专用运行时、Python 依赖、Playwright Chromium 和 Argos English→Chinese 离线翻译模型，不要求预装 Git、Python、Node 或 Java。

安装完成后，在 Codex 插件管理中确认 Life Science Research、Browser、Chrome 已启用并重启 Codex。命令窗口退出码为 0 且体检结果显示 `standard_ready=true`，才表示标准调研环境可用。

## 主要更新

- Windows 安装支持本地离线资产、企业内网镜像、官方公网源三级回退。
- 所有运行时资产通过 release manifest 的文件大小和 SHA-256 校验。
- `SHA256SUMS.txt` 使用 UTF-8 无 BOM 和 LF 换行，可在 Windows、macOS 与 Linux 校验。
- Argos 英中模型随标准离线安装包交付，并包含 OPUS-MT 模型的 CC BY 4.0 署名。
- 指标事实增加中文指标名、英文标签、中文解释、中文摘录和翻译状态，并贯通 HTML、Excel 与 Markdown 证据卡。
- 补充 Windows IANA 时区数据库依赖，并统一材料相对路径为跨平台格式。
- Java 和 Node 不是当前诺研运行时依赖，因此不进入标准包；后续需要相关控件时通过可选扩展资产提供。

## 校验与验收

`SHA256SUMS.txt` 用于核对下载文件完整性。`WINDOWS_VALIDATION_PROMPT.md` 可直接交给 Windows 环境中的 Codex 执行安装验收。

GitHub Windows Runner 已通过全量测试、Ruff、源码编译、离线资产构建和完整安装包组装。干净 Windows 10/11 电脑的实际离线安装仍属于人工验收项；严格体检未通过时，不应开始正式调研。
